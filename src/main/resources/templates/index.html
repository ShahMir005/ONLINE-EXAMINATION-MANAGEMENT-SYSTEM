Review 1 Core Technical Pillars

Every core architectural principle from Review 1 is retained and seamlessly wired into this web application.

OOP & Polymorphism

Inheritance & Types

Extends abstract User into Student and Instructor with polymorphic describe(). Questions implement generic Question<T> with concrete MultipleChoiceQuestion and TrueFalseQuestion.

JDBC CRUD

PreparedStatement

Full CRUD implementation via StudentRepository and ExamRepository. Every SQL statement uses parameterized inputs to prevent injection and safely manage generated identity keys.

Transactions

Atomic Commit & Rollback

Transactions.run(...) manages connection autoCommit boundaries. When creating exams with batches of questions or recording attempts with answers, any failure triggers an immediate, clean rollback.

Collections & Generics

Thread-Safe Cache

Uses InMemoryCache<T> backed by ConcurrentHashMap for fast O(1) lookups in ExamCatalog, along with typed List, Set, and Map.

Multithreading

Locks & Async Pool

ExamSubmissionService dispatches submissions via a 4-thread ExecutorService and CompletableFuture, guarded by individual ReentrantLock instances per student to stop duplicate attempts.

Embedded H2

Relational Schema

H2 file-backed database in ./data/exampro_v2 with 6 normalized tables, foreign key constraints, cascading deletions, and unique constraints.
